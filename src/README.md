# Source map

- `exercises.mjs` — metadata and normalized joint-pose keyframes for the preserved SVG prototype.
- `svg.mjs` — renderer for self-contained animated SVG examples.
- `app.mjs` — older dependency-free SVG gallery used by `prototype.html`.
- `exercises-3d.mjs` — ten source-clip records, license delivery notes, movement cues, steps, and primary/supporting muscle groups.
- `exercise-library.mjs` — Three.js viewer, original GLB loading/playback, neutralization of fixed source colors, camera/timeline controls, and exercise selection UI.
- `bodymap.js` — OpenGym3D MIT-licensed front/back schematic map renderer; attribution is in `../THIRD_PARTY_NOTICES.md`.

Bundled CC0 GLBs, source links, hashes, and per-asset license notes are in `../assets/3d/NOTICE.md`.
